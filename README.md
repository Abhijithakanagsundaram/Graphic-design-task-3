# Task 3 – Event Poster

## Project Title
Innovating the Future with AI – Event Poster Design

## Objective
Designed a modern promotional event poster using Canva by combining text, graphics, and futuristic visuals while following core design principles such as contrast, alignment, balance, and visual hierarchy.

## Features
- Futuristic AI-themed poster design
- Effective combination of text, graphics, and images
- Clean and readable layout
- Strong visual hierarchy and alignment
- Professional color palette and typography
- Promotional “Register Now” call-to-action section

## Tools Used
- Canva

## Design Elements
- AI robotic hand graphics
- Technology-inspired background
- Modern typography
- Event details section
- CTA button and branding elements

## Learning Outcomes
- Improved understanding of layout composition
- Learned visual communication techniques
- Applied poster and flyer design principles
- Practiced alignment, spacing, and contrast management

## Output
A professional AI event poster promoting a futuristic technology workshop.
